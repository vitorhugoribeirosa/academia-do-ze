# Trabalho do Tio Lu - Dia 27

Atividade prática da avaliação 02, com entrega no dia 27: primeira versão da camada de domínio do sistema de gerenciamento da Academia do Zé.

O projeto foi desenvolvido em C# com .NET 10, seguindo conceitos de orientação a objetos, Domain-Driven Design (DDD), herança, encapsulamento, classes abstratas, enumerações e objetos de valor.

## Estrutura da atividade

- `Entities`: entidades do domínio, como aluno, colaborador, matrícula e registros de acesso.
- `Enums`: tipos de colaborador, vínculo, planos e restrições de matrícula.
- `ValueObjects`: arquivo, CEP, CPF, e-mail, endereço, senha e telefone.

Nesta etapa, as classes contêm somente suas propriedades e construtores, conforme solicitado na atividade.
